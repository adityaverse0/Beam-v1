Build a Premium Android Quick Settings Tile for Beam (LocalSend Fork)

Create a native Android feature for my app "Beam" (a fork of LocalSend).

Goal

When the user taps the Beam tile in Android Quick Settings, it should feel like a premium system feature.

Requirements

Quick Settings Tile

- Implement using Android "TileService".
- Tile states:
  - Idle
  - Searching
  - Connected
  - Transferring
- Update icon and label according to state.
- Long press opens Beam settings.
- Tap starts Beam instantly without delay.

Launch Animation

When the tile is tapped:

- Expand into a full-screen overlay.
- Apply a soft background blur if supported.
- Use spring-based Material animations.
- Add subtle haptic feedback.
- Animate at 60–120 FPS where possible.

Discovery Screen

Instead of a simple loading spinner:

- Animated radar scan.
- Floating particles.
- Pulsing center circle.
- Animated "Searching for nearby devices..."
- Device cards fade and slide into view.
- Smooth transitions throughout.

Transfer Screen

- Circular progress ring.
- Live transfer speed.
- Remaining time.
- Animated file icon.
- Device avatar.
- Pause, resume, and cancel controls.

Success Animation

- Progress ring morphs into a checkmark.
- Gentle particle burst.
- Success haptic.
- Automatically dismiss after a short delay.

UI Design

- Minimal.
- Modern.
- Material 3.
- Rounded corners.
- Dynamic color support.
- Dark and light themes.
- Smooth motion everywhere.
- No lag or frame drops.

Performance

- Do not block the UI thread.
- Use coroutines for background work.
- Optimize animations for low-end devices.
- Keep battery usage low.

Compatibility

- Android 8.0+.
- Works as a normal app.
- No root required.
- No custom ROM required.
- No system privileges required.

Important

Do NOT modify or break LocalSend's transfer protocol or networking logic. Only enhance the Android UI, Quick Settings integration, animations, and user experience while keeping all existing functionality intact.
